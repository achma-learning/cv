Publishing

Checking your sign-in…

You are editing a draft in this browser. To put it on your live CV, give the editor permission to save to your GitHub repository.

GitHub access required

Create an access token that can reach only this repository, and nothing else in your account.

  1. Open the token page on GitHub (Settings → Developer settings → Fine-grained tokens).
  2. Give it any name and an expiry date you are comfortable with.
  3. Under Repository access, choose Only select repositories and pick the repository holding this CV.
  4. Under Permissions → Repository permissions, set:

    Contents → Read and write

    That is the only permission needed. Leave everything else alone.
  5. Press Generate token, copy it, and paste it below.

The token is kept in this browser only and is never added to your repository or sent anywhere except GitHub. Without the tick above it is forgotten when you close this tab; with it, it stays on this device until you press Sign Out. Only tick it on a computer that is yours alone.

Only repositories you own are listed. Choosing one here decides where Publish writes; GitHub still decides whether it accepts the change.
